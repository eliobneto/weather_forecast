# Weather Forecast

A simple app in flutter to get the weather forecast of your current location using the [Open-Meteo API](https://open-meteo.com/).

## Getting Started

Run this command to get the project dependences:

```text
flutter pub get
```

Run this command to execute the project:

```text
flutter run
```
